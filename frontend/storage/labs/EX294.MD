### Lab: Ansible Automation: Core Configuration & Management

This lab is designed for individuals preparing for the Red Hat Certified Engineer (RHCE) exam (EX294) or anyone looking to deepen their understanding of Ansible automation for system administration tasks. Participants will gain hands-on experience with fundamental Ansible concepts, enabling them to efficiently manage and configure multiple Linux systems.

**Lab Objectives:**

Upon completion of this lab, participants will be able to:

* **Understand Ansible Architecture:** Grasp the core components of Ansible, including control nodes, managed hosts, and inventory.
* **Configure Ansible Inventory:** Create and manage static and dynamic inventory files to organize managed hosts.
* **Write and Execute Playbooks:** Develop basic Ansible playbooks to automate common administrative tasks.
* **Utilize Ansible Modules:** Work with essential Ansible modules for package management, service control, file manipulation, and user management.
* **Manage Variables and Facts:** Understand how to use variables within playbooks and leverage Ansible facts for conditional execution.
* **Implement Handlers:** Configure handlers to trigger specific actions upon changes made by tasks.
* **Use Ad-hoc Commands:** Execute quick, single-line commands using Ansible for immediate tasks.
* **Leverage Vault for Sensitive Data:** (Optional, if time permits) Introduce the concept of Ansible Vault for encrypting sensitive data.

**Prerequisites:**

* Basic familiarity with Linux command-line interface.
* Understanding of SSH for remote access.
* A Red Hat Enterprise Linux (RHEL) 8 or 9 system configured as an Ansible control node (provided in the lab environment).
* At least two RHEL 8 or 9 systems configured as managed hosts (provided in the lab environment).

**Lab Environment:**

This lab provides a pre-configured environment with:

* 1 x Ansible Control Node (RHEL 8/9)
* 2 x Managed Hosts (RHEL 8/9)
* Pre-installed Ansible and necessary tools.

**Key RHCE Exam Objectives Covered:**

* Perform basic host management using Ansible.
* Create and manage inventories.
* Run ad hoc commands.
* Write and interpret playbooks.
* Use variables and facts.
* Implement handlers.
* Manage packages and services.
* Manage files and directories.
* Manage users and groups.

**Estimated Time to Complete:** 120 minutes

This lab provides a solid foundation for mastering Ansible automation, a critical skill for any modern Linux administrator and a key requirement for the RHCE certification.
