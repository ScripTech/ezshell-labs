### Lab: RHCSA: Essential System Administration Tasks

This lab is designed for individuals preparing for the Red Hat Certified System Administrator (RHCSA) exam (EX200) or anyone looking to build a strong foundation in Linux system administration. Participants will engage in hands-on exercises covering critical day-to-day tasks required to manage a Red Hat Enterprise Linux system.

**Lab Objectives:**

Upon completion of this lab, participants will be able to:

* **Manage Files and Directories:** Create, locate, and manage files and directories, including understanding file permissions and ownership.
* **Manage Users and Groups:** Create, modify, and delete local user accounts and groups, and manage password policies.
* **Control Services and Processes:** Start, stop, enable, and disable system services, and manage running processes.
* **Configure Networking:** Set up basic network configurations, including IP addresses, netmasks, and default gateways.
* **Manage Software Packages:** Install, update, and remove software packages using `dnf`.
* **Configure Storage:** Create and manage partitions, logical volumes (LVM), and file systems.
* **Manage System Startup:** Understand and manage the boot process and system runlevels/targets.
* **Access and Analyze System Logs:** Locate and interpret system log files for troubleshooting.
* **Implement Basic Security:** Configure firewall rules using `firewalld` and manage SELinux modes.

**Prerequisites:**

* Basic familiarity with command-line interfaces.
* No prior Linux administration experience is strictly required, but a willingness to learn is essential.

**Lab Environment:**

This lab provides a pre-configured environment with:

* 1 x Red Hat Enterprise Linux (RHEL) 8 or 9 system.
* Full root access for administrative tasks.

**Key RHCSA Exam Objectives Covered:**

* Understand and use essential tools.
* Operate running systems.
* Configure local storage.
* Create and configure file systems.
* Deploy, configure, and maintain systems.
* Manage users and groups.
* Manage security.
* Manage networking.

**Estimated Time to Complete:** 75 minutes

This lab provides the fundamental hands-on experience necessary to confidently approach the RHCSA exam and become proficient in Red Hat Enterprise Linux system administration.
