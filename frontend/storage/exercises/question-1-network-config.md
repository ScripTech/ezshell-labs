### Configuring TCP/IP and Hostname

Configure TCP/IP and hostname as follows:

* IP ADDRESS = 172.25.X.11
* NETMASK = 255.255.255.0
* GATEWAY = 172.25.X.254
* DNS = 172.25.254.254
* Hostname = serverX.example.com
