### Configuring TCP/IP and Hostname

Configure TCP/IP and hostname as follows:

* IP ADDRESS = 192.168.251.128
* NETMASK = /24
* GATEWAY = 192.168.251.2
* DNS = 192.168.251.2
* Hostname = ezetsu.lab.local
